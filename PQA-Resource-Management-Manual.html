1 · เข้าสู่ระบบ & สิทธิ์การใช้งาน

🔑

เข้าสู่ระบบด้วยอีเมล

ล็อกอินด้วย อีเมลบริษัท (เช่น you@infinitaskt.com) และรหัสผ่าน ระบบยืนยันตัวตนผ่าน Supabase มุมขวาบนจะแสดงชื่อและบทบาทของคุณ พร้อมปุ่ม ออกจากระบบ

🛡️

สิทธิ์ตามบทบาท (Role)

สิ่งที่คุณเห็นและแก้ไขได้ขึ้นกับบทบาทที่ได้รับ ดูบทบาทของคุณได้มุมขวาบน ถ้าต้องการสิทธิ์เพิ่ม ติดต่อผู้ดูแลระบบ (Admin)

บทบาท ทำอะไรได้
adminเข้าถึงและแก้ไขได้ทุกอย่าง รวมถึงเมนู Admin (ตั้งค่าข้อมูลหลัก จัดการผู้ใช้)
leadหัวหน้าทีม — จัดการโปรเจกต์ จองคิว และตรวจรับงานของทีมตัวเอง (ระบบกรองให้เห็นโปรเจกต์ที่รับผิดชอบเป็นค่าเริ่มต้น)
testerผู้ทดสอบ — ดูข้อมูลและร่วมพูดคุยในหน้า Signoff Review
viewerดูอย่างเดียว — เปิดดูทุกหน้าได้ แต่แก้ไขข้อมูลไม่ได้

2 · ศัพท์ที่ต้องรู้ก่อนใช้งาน

เข้าใจ 4 คำนี้แล้วจะใช้ทุกเมนูได้ง่ายขึ้นมาก

MD · Man-Day

หน่วยแรงงานต่อคนต่อวัน — 1 MD = ทำงานเต็มวัน, 0.5 MD = ครึ่งวัน คนหนึ่งคนใน 1 วันรับงานรวมได้ ไม่เกิน 1.0 MD ถ้าเกินคือ “ชนกัน”

Phase · เฟสของงาน

ขั้นตอนงานทดสอบ 5 เฟส แต่ละโปรเจกต์กรอกเฉพาะเฟสที่ใช้ (ดูสีและความหมายด้านล่าง)

Booking · การจองคิว

การจองคน (ทีม outsource) เข้าทำงานให้เฟสของโปรเจกต์ในช่วงวันที่กำหนด พร้อมระบุ MD ต่อวัน (หมายเหตุ: เฟส SIT ไม่ต้องจอง MD)

Conflict · งานชนกัน

เมื่อคนหนึ่งถูกจอง (รวมวันลา) เกิน 1.0 MD ในวันเดียว ระบบจะเตือนและเปิดหน้า Co-Edit ให้ปรับวันที่/MD จนไม่เกิน

ลำดับเฟส (ซ้าย → ขวา)
SIT → TC Prep → UAT → Reg → Support
SIT — System Integration Test ทดสอบระบบเชื่อมต่อ (ไม่ต้องจอง MD)
TC Prep — เตรียม Test Case ก่อนลงมือทดสอบ
UAT — User Acceptance Test ผู้ใช้ทดสอบเพื่อยอมรับงาน
Reg — Regression ทดสอบซ้ำว่าของเดิมยังทำงานปกติ
Support — ดูแลหลังส่งมอบ / ช่วงใช้งานจริง
คำว่า “จะเริ่ม · …” นำหน้าเฟส = ยังไม่เริ่ม (รออยู่ในคิว)

3 · 6 เมนูหลัก

แถบเมนูอยู่ด้านบนสุดทุกหน้า — คลิกสลับได้ทันที (เมนู Admin เห็นเฉพาะสิทธิ์ admin)

หน้าหลัก

📊 Project Gantt

ตารางเวลารวมทุกโปรเจกต์ เห็นเฟสและช่วงจองงานเป็นแถบสีบนไทม์ไลน์ — เป็นหน้าเริ่มต้นเมื่อเข้าระบบ

• คอลัมน์ซ้ายค้างไว้: ชื่อโปรเจกต์, เฟส/Booked, Action
• แถบสีน้ำตาลอ่อน = ช่วงงานของโปรเจกต์ · คอลัมน์ไฮไลต์ = วันนี้
• ป้าย 👤 2/3 = จองแล้ว/ต้องการ (แดง=ยังไม่ครบ, เขียว=ครบ) กดเพื่อจองคิว
• ปุ่มบน: + เพิ่ม Project, Collapse/Expand All, 🔎 ตัวกรอง
• ตัวกรอง: Project, UAT Lead, App, ช่วงวันที่, Phase, การจัดเรียง
• คลิกช่องวันบนแถวเฟส = เพิ่ม/แก้ Note รายวัน (มีจุดสีเมื่อมีโน้ต)
ปุ่ม Action: ✏️ แก้ไขโปรเจกต์/เฟส 🔎 เปิดรีวิว Signoff 📄 เปิดเอกสาร Signoff

👥 Outsource

ตารางคน outsource × วัน ดูว่าใครว่าง ใครถูกจอง และใครลาในแต่ละวัน

• แต่ละแถว = คน 1 คน พร้อม Role และ วันทำงานวันสุดท้าย
• ช่องสี: เต็ม=จองเต็มวัน, 0.5=ครึ่งวัน, ลา=วันลา
• จัดกลุ่ม Booked / Vacant (ถูกจอง / ยังว่าง) เปิด-ปิดได้
• ติ๊ก ⚠️ แสดงเฉพาะ Conflict เพื่อหาคนที่ถูกจองเกิน MD
• คลิกช่องวัน = เปิด Manage Booking เพิ่ม/แก้/ลบการจอง
• ปุ่ม ✏️ หน้าชื่อ = แก้ Skills และบันทึก วันลา (Leave Plan)

📅 Calendar

มุมมองปฏิทินรายเดือน เห็นภาระงานแต่ละวันแบบรวดเร็ว

• ตัวเลขในช่อง 2/3 = คนที่จองแล้ว / ที่ต้องการวันนั้น
• แสดงชื่อโปรเจกต์ที่มีงานในวันนั้น (เกิน 3 จะขึ้น +N)
• วันหยุดขึ้นชื่อวันหยุด 🎌 · เลื่อนเดือนด้วย ‹ › หรือปุ่ม “วันนี้”
• คลิกวัน = ดูรายละเอียดว่าใครทำโปรเจกต์/เฟสไหนบ้าง

📈 Dashboard

สรุปภาพรวมเป็นตัวเลขและกราฟตามช่วงเวลา (Period) ที่เลือก

• การ์ด KPI: Total MD, Booked OS, Active Projects, Working Days
• กราฟ: MD แยกตาม App (แท่ง) และสัดส่วนเฟส (โดนัท)
• 4 มุมมอง: By Project · By OS · By Lead · Signoff
• ปรับช่วง Period (Start–End) แล้วกด “แสดง” · คลิกหัวตารางเพื่อเรียง

💬 Signoff Review

พื้นที่พูดคุยและตรวจรับงาน sign-off ของแต่ละโปรเจกต์ — หน้าตาเหมือนห้องแชท

• รายการซ้าย = โปรเจกต์ที่มีวัน signoff (สลับ รายเดือน / ทั้งหมด)
• การ์ดบนสุด = ข้อมูล signoff (App, Lead, วันที่, Note, เอกสาร)
• พิมพ์ความคิดเห็น ตอบกลับเป็นเธรด และกด อีโมจิ รีแอคชันได้
• เปิดจากปุ่ม 🔎 ในหน้า Gantt หรือ Dashboard ได้โดยตรง

⚙️ Admin

เฉพาะ admin

จัดการ “ข้อมูลหลัก” (Master Data) ของทั้งระบบ — ผู้ใช้ทั่วไปจะไม่เห็นเมนูนี้

• แท็บ: Projects, Holiday, App, Phase, Tester Role, User
• เพิ่ม/แก้/ปิดใช้งานรายการ และกำหนด สิทธิ์ (Role) ให้ผู้ใช้

4 · งานที่ทำบ่อย ทำยังไง

🗓️ จองคิวทีม outsource
  1. หน้า Gantt กดป้าย 👤 x/y ที่แถวเฟส
  2. กด ➕ Book Outsource เลือกคน (เลือกได้หลายคน)
  3. ใส่ Start/End และ MD (1 หรือ 0.5) แล้ว บันทึก
  4. ถ้าชนกัน ระบบเปิด Co-Edit ให้ปรับจนไม่เกิน 1.0/วัน
🌴 บันทึกวันลาให้ outsource
  1. หน้า Outsource กดปุ่ม ✏️ หน้าชื่อคน
  2. ในหัวข้อ วันลา กด ➕ Add Leave
  3. เลือกชนิด (เต็มวัน/เช้า/บ่าย) และช่วงวันที่
  4. บันทึก — วันลาจะไปแสดงในตารางและนับรวมกับ MD
⚠️ หาคนที่งานชนกัน
  1. หน้า Outsource เปิด 🔎 ตัวกรอง
  2. ติ๊ก ⚠️ แสดงเฉพาะ Booking Conflict
  3. ชื่อที่มี ⚠️ คือถูกจอง+ลาเกิน 1.0 MD
  4. คลิกช่องวันเพื่อแก้การจองให้ลงตัว
✅ ตรวจรับงาน (Sign-off)
  1. เข้าเมนู Signoff Review หรือกด 🔎 จากหน้า Gantt
  2. เลือกโปรเจกต์ทางซ้าย ดูการ์ดข้อมูล signoff
  3. พิมพ์ความคิดเห็น/ตอบกลับในเธรด กดอีโมจิได้
  4. เปิดเอกสารด้วยปุ่ม 📄 เอกสาร Signoff

5 · คำถามพบบ่อย

ทำไมบางเมนู/ปุ่มกดไม่ได้ หรือแก้ไม่ได้?+

ขึ้นกับ สิทธิ์ (Role) ของคุณ เช่น เมนู Admin เห็นเฉพาะ admin และบางการแก้ไขต้องเป็น admin/lead ดูบทบาทได้มุมขวาบน หากต้องการสิทธิ์เพิ่มให้ติดต่อผู้ดูแลระบบ

ป้าย 👤 2/3 สีแดงกับสีเขียวต่างกันยังไง?+

ตัวเลขคือ “จองแล้ว / ที่ต้องการ” ของเฟสนั้น สีแดง = ยังจองไม่ครบตามจำนวนที่กำหนด, สีเขียว = จองครบแล้ว กดที่ป้ายเพื่อเปิดหน้าจองคิว

“Co-Edit” คืออะไร ต้องทำยังไง?+

เมื่อการจองทำให้คนคนหนึ่งมี MD รวมเกิน 1.0 ในบางวัน ระบบจะเปิดตาราง Co-Edit แสดงทุกงานของคนนั้นในวันที่ชน ให้คุณปรับ Start / End / MD ของแต่ละงานจนรวมไม่เกิน 1.0 ต่อวัน แล้วกด Save ทั้งหมด

ทำไมเฟส SIT ถึงไม่ให้จอง MD?+

SIT เป็นเฟสทดสอบเชื่อมต่อระบบที่ไม่นับเป็นงานจองทรัพยากร outsource ระบบจึงไม่แสดงป้ายจำนวนคน/ปุ่มจองในแถว SIT และไม่นับ SIT ในการคำนวณเฟสปัจจุบันหรือจำนวนที่ต้องการต่อวัน

ทำไมเข้ามาแล้วเห็นแค่บางโปรเจกต์?+

ถ้าคุณเป็น lead ระบบจะกรองให้เห็นเฉพาะโปรเจกต์ที่คุณรับผิดชอบเป็นค่าเริ่มต้น (admin เห็นทั้งหมด) และหน้า Gantt ยังกรองตามช่วงวันที่ด้วย เปิด 🔎 ตัวกรองเพื่อปรับหรือล้างเงื่อนไขได้
